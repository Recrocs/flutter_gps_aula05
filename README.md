# Flutter GPS - Aula 05

Projeto da Aula 05 de PPDM2 para testar a obtenção da localização do dispositivo.

## Funcionalidades

- Solicita permissão de localização.
- Obtém latitude atual.
- Obtém longitude atual.

## Teste

```bash
flutter pub get
flutter run
```

O professor solicitou apenas o teste deste projeto.
